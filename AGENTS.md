# Instructions for Codex

I am learning to build my first React app.

## How to help me

- Use simple, clear explanations.
- Before changing code, explain what you plan to build in plain English.
- Keep changes small and focused on one feature at a time.
- Tell me which files you changed and why.
- After making a change, tell me exactly how to test it.
- If something is unclear, explain the options simply and recommend one.

## Project priorities

- Build the core features before subscriptions, payments, or advanced features.
- Keep the app simple and easy to understand.
- Do not add features that I did not ask for.
- Do not change unrelated parts of the app.

## Code quality

- Use clear names for files, components, and functions.
- Keep code organized and readable for a beginner.
- Point out errors or security concerns in plain language.
- I personally prefer constant functions [const <function_name> = () => ...] over using the function keyword.
